# To-Do List Application

## Project Description
A simple console-based To-Do List Application developed using Python. It helps users manage their daily tasks.

## Features
- Add new tasks
- View all tasks
- Remove tasks
- Save tasks in a text file
- Load saved tasks when restarting the application

## Technologies Used
- Python
- Visual Studio Code
- File Handling

## Python Concepts
- Lists
- Functions
- Loops
- Conditional Statements
- File Handling
- String Manipulation

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python todo.py
```
